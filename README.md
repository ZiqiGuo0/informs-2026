# Ziqi Guo — INFORMS 2026

Research showcase for the INFORMS 2026 Job Market Showcase, with résumé, publication links, and contact information.

Intended website: https://ziqiguo0.github.io/informs-2026/

## Publishing

This is a static website. In Settings → Pages, select **Deploy from a branch**, then **main** and **/(root)**. No build tools are required.

## Updating

- Edit `index.html` for content and links.
- Edit `style.css` for appearance.
- Replace `Ziqi_Guo_Resume.pdf` with an updated résumé, keeping the filename unchanged.

The site URL can stay unchanged when its contents are updated, so the QR code remains usable.
